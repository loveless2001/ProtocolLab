01 / The system

A learning runtime with a hard separation of powers.

Observations, beliefs, learned models, plans, authority, commitments, and actual effects remain distinct. An acknowledgement is never counted as deployment success; completion requires public evidence and privileged scoring.

01

Learn from public behavior

A budgeted L* learner infers a finite Mealy machine from resettable replica I/O. Admission means consistent with tested traces, never proven world truth.

02

Act through authority

Every mutation crosses signed scope, epoch, budget, dispatch, and lifecycle checks. Models cannot write policy, credentials, evidence, or the environment.

03

Retain what happened

Runs keep source locks, journals, receipts, model artifacts, predictions, corrections, and replayable scoring evidence—even when the result is negative.

INPUT

Public I/O

Authenticated observations and independent sensor readings.

INFER

Belief + learner

State sets, predictions, counterexamples, admitted models.

PROPOSE

Actor / planner

Native or frozen model proposes one bounded action.

GATE

Broker + lifecycle

Authority, accounting, dispatch, evidence, replay guards.

EFFECT

Environment

Actual command application, receipts, and later scoring.

05 / Claim boundary

What the evidence does—and does not—say.

ProtocolLab reports operational agreement, formatting behavior, and bounded task outcomes at their measured scope. It does not turn those observations into broader capability claims.

Proof scopeThe Bend laws cover the encoded lifecycle semantics and declared traces, within the pinned toolchain and trust boundary.
Shadow scopeZero divergence so far is a partial-window observation. It is not a completed 14-day gate.
Model scopeJev and Qwen runs are bounded engineering diagnostics on synthetic or locked environments.
Research scopeNo confirmatory study has established H1–H5, general capability, calibration, or production suitability.
